# nvsite
[Normalsville.org](https://normalsville.org) is the website linked to this repository. To contribute to this site, make a pull request and I'll review it!

It was originally designed to be a parody site related to the comic Normalsville.
"Real" people with the exact names of the characters in the comic propose a new city named "Normalsville" be made in some U.S. state, but I thought I'd do this instead since I felt too lazy to make it.
